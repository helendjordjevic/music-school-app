# Music School Information System

## About the Project

A database information system designed for managing the main processes of a music school, including courses, professors, students, instruments, classrooms, concerts, schedules, tuition fees, and certificates.

The project focuses on database modeling and implementation, including an EER model, relational database design, SQL queries, transactions, and a layered JDBC CLI application.

## Main Features

* Management of students and professors
* Course and instrument management
* Scheduling courses and classrooms
* Concert organization and student participation
* Student course enrollment and certificates
* Tuition fee and pricing management
* Reporting and data analysis using SQL queries
* Database transactions for data modification

## Database Design

The system was designed using:

* EER modeling
* Relational database modeling
* Entity hierarchies (Student / Professor)
* Recursive relationships (student mentorship)
* Gerunds / associative entities for course enrollment
* ID-dependent entities
* SQL DDL and DML scripts

## Technologies

* Oracle Database
* SQL
* JDBC
* Java
* Layered architecture
* DAO / Service / DTO / UI Handler
